# Weather App Odin

A small weather application built while learning how to work with external APIs.

## Overview

This project fetches weather data for a city using a public weather API and displays the result in the browser. It is a simple front-end app made to practice:

- fetching data from an external API
- handling user input
- working with async/await
- rendering dynamic content in the DOM
- bundling a project with webpack

## Features

- Search for weather by city name
- Display current temperature, humidity, and feels-like temperature
- Show a friendly message for empty or invalid searches
- Responsive, modern UI

## Tech Stack

- JavaScript
- HTML
- CSS
- Webpack
- Weather API
